# Readme

## Set up your git

```
git config --global user.name "[Fatima Neurobell]"
git config --global user.email “[fatima@neurobell.com]”
```

## Log into github
```
gh auth login
```

## Make a repo
```
git init
```

```
git status
```

```
git add [file name]
```

```
git add .
```


```
git reset [file]
```

```
git commit -m "first commit"
```

```
git branch -M main
```

```
Git branch making_changes
```

```
git checkout making_changes
```

## Push to remote (github)

```
git remote add origin https://github.com/emmett-neurobell/test.git
```

```
git push -u origin main
```

## Get code from github
```
git clone https://github.com/emmett-neurobell/test
```
